# 研究者親自閱讀的文獻清單

建立日期：2026-11-11。2026-11-12 第二次調整：研究者指出「聲紋、文字線索是不是訊號」不是重點，應先讀與題目各部分**方法**直接相關的研究，從中找出自己的方法。本版依題目的四個部分（C1–C4）重排；定位用的論文移到第三級。對應暫定題目《情境未標註下智能體的情境變動偵測與選擇性記憶利用》。

**閱讀方式**：第一級讀方法章節與實驗設定，目標是回答「這個方法能不能搬到我的設定」；第二級讀需要的部分；第三級寫相關研究時再查。每篇讀完在「讀後」欄記一句：可借用什麼、缺什麼。

## 引用原則（2026-11-11）

依文獻在論文中的用途，採不同標準：

| 用途 | 標準 |
|---|---|
| 新穎性查核、相關研究章節 | **預印本也要納入**。口試委員或審查者知道的預印本若已做過你的方法，差異點就不成立；沒讀到不是理由 |

**判斷可信度看方法，不看機構**：有沒有公開程式與資料、有沒有消融實驗、有沒有多次執行與信賴區間、限制章節是否誠實。

## 讀第一級時要回答的問題

這些方法各自解決題目的一部分，但**都假設只有一個使用者，或身分已知**。讀的時候請記下：

1. 它在哪一步用到了「使用者是誰」或「情境是什麼」？如果拿掉，會壞在哪裡？
2. 它的輸出能不能變成「機率」或「信心」，讓下一個元件使用？
3. 它需要訓練嗎？只用推論時的 LLM 能不能做到？

### C1　情境變動偵測：串流中怎麼判斷「換了」

| # | 論文 | 發表狀態 | 方法重點 | 對你的用處與缺口 | 讀後 |
|---|---|---|---|---|---|
| 1 | *Human-inspired Episodic Memory for Infinite Context LLMs*／EM-LLM，arXiv:2407.09450 | ICLR 2025；有程式 | 下一個 token 的驚訝度（負對數機率）超過「移動視窗平均 + γ·標準差」判為候選邊界，再用注意力鍵的相似度圖（modularity）微調；線上、不需訓練。作者指出與 BOCPD 相似 | 驚訝度是現成、可線上計算的「換了沒」訊號。缺口：切的是 token 片段，不區分「換人」與「換話題」 | |
| 2 | *ES-Mem*，arXiv:2601.07582 | 預印本 | 兩階段：每輪抽主題→嵌入→相鄰輪互資訊落在後 35% 為候選；再請 LLM 看前後各 2 輪判斷「轉換／延續」並給信心，超過 0.75 才算邊界。有對話切分資料集評估，本機 3B 模型可跑 | 「統計初篩 + LLM 複核」的架構可借用，也有切分指標（Pk、WindowDiff）。缺口：只看話題，不看人與場景 | |
| 3 | *HingeMem*，arXiv:2604.06845 | WWW 2026 | 人、時間、地點、話題四個要素任一改變就切出邊界，並記錄原因（換人／換時間／換地點／換話題／明確轉折詞）；片段寫成連接四種要素節點的超邊 | **最接近你的 C1**：把「換人」明確列為邊界原因。缺口：在單一 session 內、說話者名字已給定；不處理「換到哪個舊情境」 | |
| 4 | Adams & MacKay (2007), *Bayesian Online Changepoint Detection*, arXiv:0710.3742 | 技術報告，廣泛引用 | 線上維護「距離上次變點多久」的機率分布 | 把 1–3 的訊號接成有機率的偵測器 | |

### 讀方法章節後的觀察（供討論，不是決定）

1–13 合起來看，每個部分都有不需訓練、可借用的做法，但彼此沒有接起來：C1 的邊界只用來決定記憶切多大；C3 的准入不知道現在是哪個情境；C4 的信念只針對單次請求。一個可以討論的方向是：**在對話流中持續維護「現在是哪個情境」的機率信念**——C1 的訊號更新它，C2 決定它指向舊情境還是新情境，C3 依它算每條記憶的適用機率，C4 在它太分散時決定要不要問。是否已有人做、是否可行，要讀完原文並和老師討論後再定。
